# Polices QALB

Aucun fichier WOFF2 n'est ajouté pour le moment : le site utilise une seule pile système (system-ui) pour éviter tout téléchargement de police et préserver les performances sur réseau mobile. Les glyphes arabes utilisent la police serif disponible localement sur l'appareil, sans requête externe.

Si une police de marque est choisie ultérieurement, ajouter ici uniquement ses fichiers WOFF2 sous licence vérifiée, puis déclarer @font-face avec font-display: swap.
